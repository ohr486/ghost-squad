# Ghost Squad プロダクト概要

Ghost Squadは、自然言語での問い合わせを構造化されたユーザーストーリーに変換するAI駆動のタスク管理プラットフォームです。

## 主要機能

**ストーリーボード機能**
- 日本語での自然言語問い合わせ処理
- OpenAI APIを使用したAI駆動ストーリー生成
- ストーリーレビュー・編集機能
- 外部カンバンシステム統合（Trello、Jira、GitHub Projects）
- WebUIでのリアルタイム進捗追跡

## アーキテクチャ

モダンなフルスタック構成：
- **バックエンド**: Python FastAPI + SQLAlchemy ORM
- **フロントエンド**: React TypeScriptアプリケーション
- **データベース**: PostgreSQL + Alembicマイグレーション
- **AI統合**: OpenAI APIによるストーリー生成
- **コンテナ化**: Docker Composeによる開発環境

## 主要ワークフロー

1. **問い合わせからストーリー生成**: ユーザーが自然言語で問い合わせ → AIが構造化ストーリーを生成 → レビュー・編集 → 外部システムへエクスポート
2. **ストーリー管理**: ストーリーの一覧表示、検索、編集、一括操作、変更履歴管理
3. **外部システム統合**: Trello、Jira、GitHub Projectsとの同期、カスタムフォーマットでのエクスポート

## 対象ユーザー

非公式な要件を構造化されたユーザーストーリーに変換する必要がある開発チームとプロジェクトマネージャー。
